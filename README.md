# Forever Young Performance website

Static HTML site hosted on Netlify (no build step; `publish = "."`).

- Pages: `index.html`, `pricing.html`, `about.html`, `apply.html`, `privacy.html`, `thanks.html`, `404.html`
- Shared styles/scripts: `assets/css/site.css`, `assets/js/site.js`
- Media: `assets/media/` (background videos + posters), `assets/img/` (responsive images)
- Forms: Netlify Forms (`application`, `blueprints-waitlist`). Email notifications are configured in the Netlify UI.
- Redirects and headers: `netlify.toml`
- `fyp-redesign-kit/` is local reference material and is not committed.
